Splice for Windows (x64) - bundled third-party software
=======================================================

The installer contains three unmodified upstream distributions. Splice runs
Python and FFmpeg as separate programs; it does not link to them. The
versions and SHA-256 checksums below are the ones desktop/windows/build.py
pins and verifies.


FFmpeg 9.1 (resources\ffmpeg)
-----------------------------
Build:    gyan.dev "full_build-shared" 9.1, 64-bit (ffmpeg.exe, ffprobe.exe
          and the FFmpeg DLLs; ffplay is not included)
Archive:  https://github.com/GyanD/codexffmpeg/releases/download/9.1/ffmpeg-9.1-full_build-shared.zip
SHA-256:  d010a19b78d5eae62dca8d4c7f195acd56dae8ed6fb85f72821edd9437da2898
License:  GNU General Public License, version 3 (LICENSE.txt in that folder).

This FFmpeg is built with --enable-gpl --enable-version3 and links GPL
libraries (among them x264, x265, librubberband and vid.stab), so the
FFmpeg files are distributed under the GPL v3 as a whole. It is not built
with --enable-nonfree. BUILD-CONFIGURATION.txt lists the configuration and
every library with its version; ffmpeg.exe -buildconf prints the same.

Corresponding source:
  FFmpeg:    https://github.com/FFmpeg/FFmpeg/commit/74e4393595
  Libraries: the revisions listed in BUILD-CONFIGURATION.txt, as built by
             https://www.gyan.dev/ffmpeg/builds/
This installer does not include those sources. As the distributor of these
GPL binaries, the Splice project will provide the complete corresponding
source for the FFmpeg files in this installer on request, for at least three
years after this version was last distributed; ask through the project's
issue tracker.

Libraries Splice depends on in this build, with the versions gyan.dev reports:
  x264 0.165.3223 (GPL-2.0+)          x265 4.3 (GPL-2.0+)
  SVT-AV1 4.3.0 (BSD-3-Clause-Clear)  zimg 3.0.6 (WTFPL)
  vid.stab 1.1.0 (GPL-2.0+)           Rubber Band 4.0.0 (GPL-2.0+)
  FreeType 2.15.0 (FTL/GPL-2.0)       HarfBuzz 15.1.0 (MIT)
  FriBidi 1.0.18 (LGPL-2.1+)          libass 0.17.5 (ISC)
  dav1d 1.5.4 (BSD-2-Clause)          Opus 1.6.1 (BSD-3-Clause)
